# 🌱 Green Steps

**Green Steps** is an interactive environmental web project that helps users make better decisions about items they no longer need.

## 🌍 Project Idea

The user can capture or upload a photo of an item, identify its type, choose its condition, and then receive a suitable next step: **donation, exchange, recycling, reuse, or safe disposal**.

The project turns a simple unwanted item into a clear environmental action.

## ✨ Main Features

- 📸 **Capture or Upload** — add an item using the camera or an image from the device.
- 🤖 **Item Recognition** — identify the waste category and show the analysis result.
- 👍 **Condition Selection** — choose whether the item is good, needs repair, or is in bad condition.
- 🎁 **Donation Action** — record the item as prepared for donation and show it in the user's activity.
- 🔄 **Exchange Action** — record the item as an exchange and show the interaction in the user's activity.
- ♻️ **Smart Recycling Choices** — for recyclable items, the user can:
  - 📍 Find a nearby recycling location.
  - 🏠 See a simple home-recycling / reuse idea with an illustrative image and practical tips.
  - ▶️ Open YouTube search results for recycling ideas for the selected item.
- 📍 **Nearby Places** — open relevant recycling or disposal locations based on the user's location.
- 🛡️ **Safe Disposal Guidance** — provide safety advice for different waste types.
- 🌍 **Environmental Impact** — track reused items, recycled items, avoided waste, and estimated kilograms of waste avoided.
- 📝 **My Activity** — show recent actions so the user can see that their choices are being recorded and reflected in the website.
- 💾 **Saved Progress** — keep the user's environmental activity available when they return to the website.

## 🎯 Project Goal

Green Steps encourages people to move from simply throwing things away to choosing a more responsible next step.

> **Small Steps. Big Change. 🌱🌍**

## 🌿 User Journey

**Add an Item → Analyze → Choose Condition → Choose an Action → See Your Environmental Impact**

## 💚 Green Steps
